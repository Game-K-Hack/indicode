## Что такое indicode?

В _LEGO Indiana Jones: The Original Adventures_ чит-коды вводятся на колесе из 6 символов
в классе Барнеттского колледжа: каждый символ прокручивается вверх или вниз по одному.
Делать это вручную медленно и легко ошибиться.

**indicode** сделает это за вас. Вы выбираете нужные коды, программа вычисляет кратчайший
путь между символами, а затем эмулирует нажатия клавиш, чтобы ввести их автоматически —
один код за другим.

## Возможности

- **Ввод за один проход** — выберите несколько кодов, и они будут введены подряд.
- **Навигация по кратчайшему пути** — для каждого символа выбирается вверх или вниз, чтобы свести движения к минимуму.
- **Настраиваемые клавиши** — задайте свои клавиши для вверх / вправо / вниз / влево / подтвердить.
- **Задержка старта и обратный отсчёт** — даёт время вернуться в игру.
- **9 языков** — английский, французский, немецкий, испанский, итальянский, японский, корейский, русский, китайский (автоопределение).

## Требования

- Python 3.10+
- [`pynput`](https://pypi.org/project/pynput/) и [`colorama`](https://pypi.org/project/colorama/)

```bash
pip install -r requirements.txt
```

## Использование

```bash
python main.py
```

1. Выберите нужные коды (`a` — выбрать все, `v` — подтвердить).
2. Настройте клавиши (вверх, вправо, вниз, влево, подтвердить).
3. Задайте задержку старта и вернитесь в игру с доской, показывающей `(A) A A A A A`.
4. Расслабьтесь, пока indicode всё вводит.

> Принудительно задать язык можно через переменную окружения `INDICODE_LANG` (например, `INDICODE_LANG=ru`).
